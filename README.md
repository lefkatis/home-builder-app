# 🏡 Home Provisions Builder (Έξυπνες Πρόνοιες Κατοικίας & SQLite)

Ένα σύγχρονο, διαδραστικό εργαλείο σχεδιασμού και επιλογής τεχνικών προνοιών (ηλεκτρολογικών, υδραυλικών, έξυπνου σπιτιού, δικτύου, κλιματισμού και ασφάλειας) για νέες κατοικίες και ανακαινίσεις, με άμεση αποθήκευση σε βάση δεδομένων **SQLite**.

---

## 🚀 Χαρακτηριστικά

1. **📝 Διαδραστικό Ερωτηματολόγιο (8 Ενότητες)**:
   - Βασικά χαρακτηριστικά κατοικίας (δωμάτια, όροφοι, ensuite, laundry, pantry, parking, κήπος, πισίνα, βοηθητικό σπίτι κ.α.).
   - Έξυπνο σπίτι (έξυπνα ρελέ, ουδέτερος, βαθιά κουτιά 6cm, touch panel 150cm, κουρτίνες, αισθητήρες mmWave).
   - Δικτυακή υποδομή & Server Rack (Cat6, PoE Access Points, rack μηχανοστασίου, doorbell PoE).
   - Ηλεκτρολογικά & Πρότυπα Κύπρου / BS 7671 (shaver units στα μπάνια, EV charger 32A, πρίζες νησίδας).
   - Κουζίνα & Υδραυλικά (4x πρίζες κάτω από νεροχύτη για RO/chiller/boiler/σκουπιδοφάγο, 1/4" σωληνάκι στο ψυγείο).
   - Κλιματισμός, Ενδοδαπέδια & Μηχανικός Εξαερισμός.
   - Ασφάλεια & CCTV (μαγνητικές επαφές, θραύση, PoE κάμερες, κεντρικό UPS).
   - Εξωτερικοί χώροι, αυτόματο πότισμα & BBQ.

2. **⚡ Αυτόματη Παραγωγή Εξατομικευμένων Προνοιών**:
   - Παραγωγή πλήρους λίστας προνοιών με σύμβολα IEC 60617.
   - Διαδραστική σημείωση ολοκλήρωσης με άμεσο συγχρονισμό στη βάση δεδομένων SQLite.

3. **🔀 Διαδραστικό Διάγραμμα Ροής**:
   - Δέντρο σχέσεων χώρων $\to$ παροχών με Dagre & ReactFlow.

4. **🛒 Εκτίμηση Εξοπλισμού & Προϋπολογισμός (€)**:
   - Αυτόματος υπολογισμός απαιτούμενων ποσοτήτων (Shelly, APs, κάμερες, rack κλπ.) και κόστους.

5. **💾 SQLite Database Persistence**:
   - Ενσωματωμένο `node:sqlite` module (zero external dependencies).
   - Όλες οι επιλογές και οι αλλαγές καταγράφονται στο αρχείο `pronies_app.sqlite`.

---

## 🛠️ Εκκίνηση Εφαρμογής

### 1. Εγκατάσταση εξαρτήσεων:
```bash
npm install
```

### 2. Εκκίνηση SQLite API Server & Frontend:
```bash
npm run dev:all
```

* Frontend: `http://localhost:5174/`
* SQLite API Server: `http://localhost:3001/`
